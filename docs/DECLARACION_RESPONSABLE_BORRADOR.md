# DECLARACIÓN RESPONSABLE DEL SISTEMA INFORMÁTICO DE FACTURACIÓN

**ESTADO: BORRADOR. NO SUSCRIBIR HASTA TERMINAR VALIDACIÓN TÉCNICA Y COMPLETAR LOS DATOS DEL PRODUCTOR.**

La versión visible y descargable se genera también dentro de ARW2026 PRO → DECLARACIÓN SIF. Debe conservarse una declaración por cada versión.

Campos mínimos, en orden:

a) Nombre del sistema.
b) Código identificador único del sistema.
c) Identificador completo de versión.
d) Componentes hardware/software, descripción y funcionalidades.
e) Indicación de funcionamiento exclusivo o no como VERI*FACTU.
f) Indicación de soporte a uno o varios obligados tributarios.
g) Tipos de firma utilizados si funciona como NO VERI*FACTU.
h) Persona o entidad productora.
i) NIF del productor.
j) Dirección postal completa del productor.
k) Declaración de cumplimiento normativo de la versión.
l) Fecha y lugar de suscripción.

El anexo recomendado documentará contacto, URL y explicación técnica de cumplimiento.
